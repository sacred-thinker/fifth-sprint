# Фитнес-трекер

Этот модуль предназначен для расчета и вывода результатов различных видов тренировок: бега, ходьбы и плавания.

## Возможности

Модуль предоставляет следующие функции:

Расчет дистанции тренировки

Расчет средней скорости

Расчет расхода энергии (калорий)

Формирование информационного сообщения с результатами

Для каждого типа тренировки реализованы специфические алгоритмы расчета:

Бег: расчет калорий учитывает среднюю скорость и вес пользователя

Ходьба: расчет калорий учитывает скорость, рост и вес пользователя

Плавание: расчет калорий учитывает длину бассейна, количество пересечений и вес пользователя

## Используемые инструменты и технологии

Язык программирования: Go (Golang)

Основные пакеты:

fmt - для форматированного вывода

math - для математических операций

time - для работы с продолжительностью тренировки

Принципы ООП:

Структуры для представления типов тренировок

Интерфейсы для полиморфного поведения

Переопределение методов для специфичных расчетов

## Структура проекта

Проект состоит из:

Базовой структуры Training с общими полями для всех тренировок

Специализированных структур:

Running для бега

Walking для ходьбы

Swimming для плавания

Интерфейса CaloriesCalculator для унифицированного расчета калорий

Структуры InfoMessage для хранения и форматирования результатов

Функции ReadData для обработки данных тренировки

## Установка и запуск

Убедитесь, что у вас установлен Go (версия 1.16 или выше)

Скопируйте код в файл main.go

Запустите программу:

go run main.go

## Заключение

Этот модуль предоставляет удобный инструмент для отслеживания и анализа различных видов физической активности. Благодаря использованию принципов ООП и интерфейсов, система легко расширяема для добавления новых типов тренировок.
